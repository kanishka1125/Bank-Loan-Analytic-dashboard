# 🏦 Bank Loan Analytics Dashboard | Power BI

An interactive Power BI dashboard built to analyze bank loan portfolio
performance, lending activity, repayment behavior, and borrower trends.

> 💡 The dashboard is fully interactive. Use the filters, navigation buttons,
> and visual interactions to explore the loan portfolio.

## 🎯 Project Objective

The objective of this project is to analyze bank lending activities and
portfolio performance through an interactive Power BI dashboard.

The dashboard helps analyze:

- Loan application trends
- Good vs Bad loan performance
- Funded amount vs amount received
- Loan repayment behavior
- Interest rate trends
- Debt-to-Income (DTI) ratio
- Regional loan distribution
- Loan purpose and borrower characteristics

## 📈 Dashboard Pages

### 1. Summary

The Summary page provides a high-level view of the bank's loan
portfolio.

It includes:

- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Good Loan Applications
- Bad Loan Applications
- Funded Amount vs Repayment
- Loan Applications by Loan Status
- Average Interest Rate by Loan Status
- Average DTI Ratio by Loan Status

### 2. Overview

The Overview page provides deeper analysis of loan application trends.

It includes:

- Loan Applications by Month
- Loan Applications by State
- Loan Applications by Loan Term
- Loan Applications by Home Ownership
- Loan Applications by Purpose
